# 1. Описание проекта

## Название

Scauta

---

## История названия

Scauta происходит от слова **Scout** — разведчик, исследователь, тот, кто первым находит нужный путь.

В реальном мире scout:

- исследует территорию;
- быстро находит нужный объект;
- прокладывает путь;
- возвращается с результатом.

Scauta выполняет ту же роль в цифровом пространстве:

- знает структуру пользовательских закладок;
- быстро находит нужный ресурс;
- помогает ориентироваться среди тысяч ссылок;
- открывает нужную страницу за несколько секунд.

Scauta — это интеллектуальный поиск и навигация по существующим браузерным закладкам.

---

# 2. Назначение проекта

Scauta — это расширение браузера для мгновенного поиска по закладкам браузера.

Главная задача:

Позволить пользователю открыть любую нужную закладку через несколько секунд с помощью:

- горячей клавиши;
- fuzzy search;
- клавиатурной навигации.

---

# 3. Главный сценарий использования

Пользователь:

1. Нажимает shortcut:

```

Cmd + Shift + Space

```

или:

```

Ctrl + Shift + Space

```

2. Открывается поисковое окно.

3. Пользователь вводит:

```

kub graf

```

4. Scauta находит:

```

Kubernetes Grafana Dashboard

[https://grafana.company.com](https://grafana.company.com)

```

5. Пользователь нажимает Enter.

6. Открывается вкладка.

---

# 4. Основные принципы UX

## Keyboard-first

Основное управление должно происходить без мыши.

Пользователь должен иметь возможность:

- открыть поиск;
- написать запрос;
- выбрать результат;
- открыть ссылку.

---

## Минимальное количество действий

Целевой сценарий:

```

Shortcut

↓

Typing

↓

Enter

↓

Open

```

Не более 3 действий.

---

## Быстрый доступ

Поиск должен работать мгновенно:

Цель:

- открытие интерфейса < 100 ms;
- поиск < 50 ms для 10 000 закладок.

# 9. Источник данных

ВАЖНО:

Scauta НЕ использует собственное хранилище закладок.

Источник истины:

браузер пользователя.

---

Использовать:

Chrome Bookmark API:

```
chrome.bookmarks
```

---

При запуске:

1. Получить дерево закладок.
2. Построить локальный индекс в памяти.
3. Выполнять поиск по индексу.
